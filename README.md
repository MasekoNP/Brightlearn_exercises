# Brightlearn_exercises
## SQL Fundamentals & Advanced Database Queries

Welcome to my SQL practice repository! This repository contains a collection of comprehensive SQL query exercises covering foundational concepts to advanced data analytics operations, including filtering, aggregations, date manipulations, conditional logic, and NULL handling.

The challenges in this repository are part of the structural coursework for the **BrightLight Tutorials** and **BrightLearn** Data Analytics programs.

## Detailed Exercise Overview

### Exercise 1: SQL Fundamentals (SELECT & Filtering)  
Focuses on extracting, sorting, and restricting rows using basic operational logic.
* **Key Concepts:** `SELECT`, `SELECT DISTINCT`, `ORDER BY`, `LIMIT`, `WHERE` clauses.
* **Advanced Filters:** Logical operators (`AND`, `OR`, `NOT`), evaluated list constraints (`IN`), and complex multi-condition filtering combinations.

### Exercise 2: Aggregate Functions & Grouping
Focuses on summary statistics, groupings, and group-level restrictions.
* **Key Concepts:** `COUNT()`, `SUM()`, `AVG()`, `MIN()`, `MAX()`.
* **Group Clauses:** Constructing group buckets using `GROUP BY`, multi-column ordering, and applying evaluation rules on aggregated groups using `HAVING`.

### Exercise 3: SQL CASE Statement  
Focuses on injecting logical, conditional control statements straight into queries.
* **Key Concepts:** `CASE WHEN ... THEN ... ELSE END`.
* **Real-World Use Cases:** Dynamic classification buckets (e.g., product price categories, low/medium/high asset evaluations, dynamic grading charts, performance metric labeling, and conditional discounts flags).

### Exercise 4: Advanced Joins, UNIONs, Filtering & Aggregates  
Focuses on relational data modeling, merging datasets horizontally, and compiling structured results.
* **Relational Joins:** `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, and `FULL OUTER JOIN` implementations.
* **Set Operations:** Merging matching structures with `UNION` (unique results) and `UNION ALL` (including duplicates).
* **Complex Grouping:** Advanced queries requiring `GROUP BY` paired with logical `HAVING` filters across connected relations.

### Exercise 5: Advanced SQL — NULL Functions  
Focuses on defensive data design, handling unknown values, and implementing fallback defaults.
* **Key Functions:** `IFNULL()`, `ISNULL()`, `COALESCE()`.
* **Edge Cases Managed:** Cleaning missing values to standard representations (`0`, `'Pending'`, `'Not Assigned'`, `'TBD'`), cascading fallback values through multiple columns, and computing operations securely across nullable data.

### Exercise 6: Advanced SQL — DATE Functions  
Focuses on tracking temporal metrics, manipulating timestamp intervals, and formating strings.
* **Key Concepts:** `DATEADD()`, `DATEDIFF()`, `CURRENT_DATE`, `DATE_PART()`, and `EXTRACT()`.
* **Formatting Actions:** Converting complex dates/timestamps to string representations using `TO_CHAR()` and rebuilding date types from independent integers using `DATE_FROM_PARTS()`.
